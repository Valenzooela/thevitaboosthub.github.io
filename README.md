## Hosting on GitHub Pages

1. **Create a new GitHub repository** named `thevitaboosthub.github.io` (replace with your username if desired)

2. **Clone the repo locally:**
   ```bash
   git clone https://github.com/yourusername/thevitaboosthub.github.io.git
   cd thevitaboosthub.github.io
   ```

3. **Copy the `index.html` file into the repo**

4. **Commit and push:**
   ```bash
   git add index.html
   git commit -m "Add business card landing page"
   git push origin main
   ```

5. **Enable GitHub Pages:**
   - Go to repository Settings → Pages
   - Set source to `main` branch
   - Your site will be live at `https://yourusername.github.io`

## Custom Domain (Optional)

To use a custom domain:
1. Add a `CNAME` file to the repo with your domain name
2. Update your domain's DNS settings to point to GitHub Pages
3. Enable HTTPS in repository settings
